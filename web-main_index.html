JOIN · 连接教程

一分钟上岛

服务器地址：senyumc.top

备用地址 play.senyumc.top:13347（主地址连不上时使用；“复制地址”复制的是主地址）

☕

Java 版连接步骤

  1. 打开 Minecraft Java 版 26.2，进入多人游戏
  2. 添加服务器，地址填 senyumc.top:33347
  3. 选中服务器直接加入，离线账号也可游玩
  4. 首次进入按提示 /register 注册、/login 登录
📱

基岩版连接步骤

  1. 打开基岩版，选择 添加外部服务器
  2. 服务器地址填 senyumc.top
  3. 端口：33347
  4. 保存后直接进入，26.0+ 基岩版本均可连接
基岩版可以进服吗？▼
可以。服务器通过 Geyser / Floodgate 实现基岩互通，手机、主机、Win10 基岩版（26.0+ 主流版本）均可连接，与 Java 玩家同世界游玩。
需要 Minecraft 正版账号吗？▼
不需要。离线账号即可直接游玩，首次进入注册登录账号即可，支持绑定邮箱找回密码。
连接失败怎么办？▼
① 确认地址填写完整（主地址 senyumc.top:33347，连不上换备用 play.senyumc.top:13347）；② 检查自己的网络；③ 确认游戏版本要求（Java 26.2，旧版本 Java 客户端也可兼容加入 / 基岩 26.0+）。仍无法连接可在 QQ 群内求助。
游戏和启动器去哪里下载？▼
Java 版推荐 下载页 里的 PCL2 / HMCL 启动器；基岩版安卓可以在 mcapks.net 下载国际版客户端。装好后再回到连接教程添加服务器即可。

ECONOMY · 经济与交易

健康经济 累进税防通胀

官方商店零手续费；玩家拍卖行成交时按卖家当前余额档累进收税，税金直接销毁回收出经济系统，长期抑制通胀。

🏪

官方商店 /shop

一站式收购出售，物品定价透明稳定，急缺什么随时补给。

🔨

玩家拍卖行 /ah

自由定价挂牌交易，每人最多 10 件在售，7 天未售出自动过期退回。成交时向卖家按余额档累进税 1%~20% 收取税金。

🔥

税金销毁 回收防通胀

拍卖税金不进任何账户，直接从经济系统销毁。余额越高税率越高，巨富多缴、新人少缴，金币长期保值。
