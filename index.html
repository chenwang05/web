🛡️ 领地保护（Dominion）

手持木锄，左键、右键各选一个点围成长方体，/dom create 一键成领地（dominion 可简写为 dom），价格 0.07 金币/方块（只按底面积计费，高度不计，删除不退款）。手持线点击方块还能查看脚下领地归属。每人最多 30 个领地，单领地最大 128×128，子领地可嵌套 3 层；180 天不上线领地会自动清理。

/dom 管理菜单 /dom create <名称> /dom tp <领地>

Java 版连接步骤

  1. 打开 Minecraft Java 版 26.3（建议与服务器版本相同），进入多人游戏
  2. 添加服务器，地址填 senyumc.top:33347
  3. 选中服务器直接加入，离线账号也可游玩
  4. 首次进入按提示 /register 注册、/login 登录
📱

基岩版连接步骤

  1. 打开基岩版，选择 添加外部服务器
  2. 服务器地址填 senyumc.top
  3. 端口：33349
  4. 保存后直接进入，基岩版本均可连接
基岩版可以进服吗？▼
可以。服务器通过 Geyser / Floodgate 实现基岩互通，手机、主机、Win10 基岩版均可连接，与 Java 玩家同世界游玩。
需要 Minecraft 正版账号吗？▼
不需要。离线账号即可直接游玩，首次进入注册登录账号即可，支持绑定邮箱找回密码。
连接失败怎么办？▼
① 确认地址填写完整（Java 版 senyumc.top:33347、基岩版 senyumc.top:33349）；② 检查自己的网络。仍无法连接可在 QQ 群内求助。

ECONOMY · 经济与交易

健康经济 累进税防通胀

官方商店零手续费；玩家拍卖行成交时按卖家当前余额档累进收税，税金直接销毁回收出经济系统，长期抑制通胀。

🏪

官方商店 /shop

一站式收购出售，物价随全服供需动态浮动，货价更真实。

🔨

玩家拍卖行 /ah

自由定价挂牌交易，每人最多 10 件在售，7 天未售出自动过期退回。成交时向卖家按余额档累进税 1%~20% 收取税金。

🔥

税金销毁 回收防通胀

拍卖税金不进任何账户，直接从经济系统销毁。余额越高税率越高，巨富多缴、新人少缴，金币长期保值。
