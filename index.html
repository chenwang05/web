/cd 主菜单 /sethome <名称> /home /back /etp 互传菜单 /tpr 随机传送

🛡️ 领地保护（Dominion）

手持木锄，左键、右键各选一个点围成长方体，/dom create 一键成领地（dominion 可简写为 dom），价格 0.7 金币/方块（只按底面积计费，高度不计，删除不退款）。手持线点击方块还能查看脚下领地归属。每人最多 30 个领地，单领地最大 128×128，子领地可嵌套 3 层。

/dom 管理菜单 /dom create <名称> /dom tp <领地>

💰 经济与商店

货币为金币。官方商店 /shop 一站式收购出售，玩家拍卖行 /ah 自由定价交易（每人最多 10 件在售，上架 7 天未售出自动过期）。商店交易采用超额累进税制，由出售方按余额分档缴税。

/balance 查询余额 /pay <玩家> <金额> /balancetop 财富榜 /shop 官方商店 /ah 拍卖行 /ah sell <价格> 上架

/skills 技能菜单 /stats 属性面板 /mana 法力值

Java 版连接步骤

  1. 打开 Minecraft Java 版 1.21.1+，进入多人游戏
  2. 添加服务器，地址填 senyumc.top 并补充端口
  3. 选中服务器直接加入，离线账号也可游玩
  4. 首次进入按提示 /register 注册、/login 登录
📱

基岩版连接步骤

  1. 打开基岩版，选择 添加外部服务器
  2. 服务器地址填 senyumc.top
  3. 端口：进群查看群公告 获取完整端口
  4. 保存后直接进入，全版本基岩均可连接
基岩版可以进服吗？▼
可以。服务器通过 Geyser / Floodgate 实现基岩互通，手机、主机、Win10 基岩版全版本均可连接，与 Java 玩家同世界游玩。
需要 Minecraft 正版账号吗？▼
不需要。离线账号即可直接游玩，首次进入注册登录账号即可，支持绑定邮箱找回密码。
连接失败怎么办？▼
① 确认地址与端口填写完整（端口在 QQ 群公告查看）；② 检查自己的网络；③ 确认游戏版本符合要求（Java 1.21.1+ / 基岩 26.0+）。仍无法连接可在 QQ 群内求助。

ECONOMY · 经济与税收

超额累进税制

商店交易按出售方账户余额分档收税——余额越高，超出部分税率越高，防止贫富垄断，税收统一进入服务器公共经济池。

玩家账户余额区间对应税率
≤ 10,000 金币1%
≤ 100,000 金币2%
≤ 250,000 金币3%
≤ 500,000 金币4%
≤ 1,000,000 金币5%
≤ 2,500,000 金币10%
≤ 5,000,000 金币12%
＞ 5,000,000 金币20%
  • 税收仅在商店交易时自动扣除，由出售方承担。
  • 商店店主变更需通过正规流程，禁止随意转移店铺所有权。
  • 系统尊重物品标签属性，附魔、自定义物品完整显示信息。
  • 禁止利用商店 BUG 刷钱、刷物品，违者按三级违规处理。
