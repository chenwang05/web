✅ 装好之后怎么进服

  1. Java 版：启动器里安装 / 选择 Minecraft 26.2，点启动进入游戏。
  2. 多人游戏 → 直接连接（或添加服务器），地址填 senyumc.top:33347（连不上换备用 play.senyumc.top:13347）。
  3. 基岩版：好友页签 → 添加服务器，地址同样填 senyumc.top:33347（双端同地址同端口）。
  4. 进服后按提示 /register 注册密码，然后在 /cd 主菜单领新手礼包。
PCL2 和 HMCL 收费吗？▼
都完全免费且开源。PCL2 若喜欢可以到爱发电支持作者，但下载与使用本身不收费。
下载哪个游戏版本？▼
Java 版选 26.2（旧版本客户端也可兼容加入）；基岩版 26.0+ 均可进服。版本以后更新时本页与玩家手册会同步。
启动器报"缺少 Java"怎么办？▼
PCL2 / HMCL 都支持自动下载并管理 Java 运行环境，按提示一键安装即可；也可以让启动器使用自带的 Java 运行时。
基岩版和 Java 版能一起玩吗？▼
能。服务器通过 Geyser 实现双端同服，手机、主机、电脑玩家在同一个世界里生存。
