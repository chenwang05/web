服务器玩家功能指南

本指南面向全体玩家，介绍服务器内各插件的玩法和常用命令。

输入 /cd 可以打开服务器主菜单，绝大多数功能都能在菜单里一键直达。

目录

一、注册与登录 二、服务器主菜单 三、传送与家园 四、世界一览 五、经济与商店 六、领地系统 七、技能系统 八、每日签到 九、飞行时间 十、姿势互动 十一、抱起小伙伴 十二、假人系统 十三、皮肤更换 十四、QQ群互通

一、注册与登录

首次进入服务器需要注册，之后每次登录都需要输入密码。

命令 说明
/register <密码> <重复密码> 首次进入时注册账号
/login <密码> 登录
/changepassword <旧密码> <新密码> 修改密码
/logout 退出登录
/email add <邮箱> <重复邮箱> 绑定邮箱，用于找回密码
  • · 密码长度要求：8 ~ 26 位，请勿使用过于简单的密码。
  • · 密码只用于本服务器，管理员不会向你索要，谨防诈骗。

二、服务器主菜单（/cd）

输入 /cd 打开主菜单，包含以下快捷入口：

  • · 返回主城 / 家园世界 / 资源世界 / 返回上一位置
  • · 玩家传送请求（/tpa 管理）
  • · 我的私人家园、领地圈地
  • · 玩家拍卖行、物品回收 / 商店
  • · 每日签到、新手礼包
  • · 原地坐下、皮肤更换中心
  • · 服务器规章制度、玩家竞技场

三、传送、家园

家园系统

命令 说明
/sethome <名称> 在脚下设置家（默认权限组最多可设 3 个）
/home [名称] 回家
/delhome <名称> 删除家

传送

命令 说明
/back 返回上次传送/死亡的位置
/tpa <玩家> 请求传送到某玩家身边
/tpahere <玩家> 请求某玩家传送到你身边
/tpaccept / /tpdeny / /tpacancel 接受 / 拒绝 / 取消传送请求
/warp <名称> / /warps 前往地标 / 查看地标列表（如 lobby 主城、shop 商店等）
/tpr 随机传送（默认送往资源世界，范围 100~1500 格），适合出门挖矿开荒

传送有 60 秒冷却，请合理安排。

四、世界一览

服务器包含以下世界（可在主菜单快速传送）：

世界 说明
大厅（主城） 出生点与主城，由地标 lobby 前往
家园世界 建家、圈地的主要生存世界
资源世界 公共资源采集世界，/tpr 随机传送默认目的地
玩家竞技场 PvP 对战区域
下界 / 末地 正常生存维度

五、经济、商店与网页商店

服务器货币为金币（$）。

金币相关

命令 说明
/balance（/bal） 查询余额
/pay <玩家> <金额> 向其他玩家转账
/balancetop 查看全服财富排行

网页商店

浏览器打开 https://shop.senyumc.top 即可使用网页商店，支持市场交易、拍卖、邮件领取、排行榜等功能，游戏内外的货币与物品数据实时同步。

游戏内配套命令（/ws）

命令 说明
/ws gui / /ws home 打开商店界面
/ws password <密码> 设置网页商店的登录密码
/ws market 打开市场
/ws claim 领取网页上购买的物品
/ws mailbox 打开邮箱
/ws recharge 充值
/ws gamecoin / /ws shopcoin 查询游戏币 / 商店币

六、领地系统

用木锄即可圈地，保护你的建筑不被他人破坏：

  1. 手持木锄，左键方块选第一个点，右键方块选第二个点（两点确定一个长方体区域，自动包含全高度）。
  2. 输入 /dominion create <领地名称> 创建领地，创建时按方块数量扣费。
  3. 手持线点击方块，可查看脚下是哪个领地、归谁所有。
  4. 输入 /dominion 打开领地管理菜单，成员管理、分组权限、访客权限等都在菜单里点点即可完成。

规则与限制

  • · 每人在主世界最多创建 30 个领地（含子领地），单领地最大 128 × 128，最小 4 × 4。
  • · 价格 0.7 金币/方块，圈地必须是长方形。
  • · 子领地最多嵌套 3 层。
  • · /dominion tp <领地> 可传送到自己的领地（传送延迟 5 秒、冷却 10 秒，期间移动会取消）。

七、技能系统

玩游戏就能涨经验！挖矿、种田、钓鱼、战斗等行为都会提升对应技能等级，升级解锁被动能力和法力技能。

命令 说明
/skills 打开技能菜单，查看所有技能与升级路线
/stats 查看自己的属性面板
/top [技能] 查看全服排行
/mana 查看法力值
/sources <技能> 查看某技能的经验来源
/claimitems 领取等级奖励物品

已开启的 11 项技能

农业、伐木、采矿、钓鱼、挖掘、射箭、防御、战斗、敏捷、炼金、附魔（满级均为 100 级）。

八、每日签到

每天输入 /signin（或 /litesignin）打开签到界面，点一下即可领取当日奖励。

  • · 每日签到可得 150 金币。
  • · 连续签到有额外奖励：如连签 3 天奖励翻倍、连签 7 天可获特殊装备与金苹果、周日有加餐、累计签到满 100 天更有大奖。
  • · 断签了也不用慌，可以使用补签卡补签。

九、飞行时间

飞行时间按分钟计费，飞行时屏幕上方有倒计时条。

命令 说明
/fly buy <数量> 购买飞行时间，50 金币/分钟（可用 m 分钟、h 小时、d 天作单位）
/fly time 查看剩余飞行时间
/fly pause 暂停倒计时（站着休息时省钱）
/fly resume 恢复倒计时

飞行时间仅限主世界使用，累计上限详见 /fly buy 提示。签到活动、节日活动也会赠送飞行时间。

十、姿势互动

命令 说明
/sit 原地坐下（也可以空手右键楼梯、台阶、地毯直接坐下）
/lay 原地躺下
/crawl 爬行
/legsup / /spin / /bellyflop 翘腿 / 旋转 / 肚皮蹲等趣味姿势

潜行即可起身。还可以坐到其他玩家头上（欢乐加倍）。

十一、抱起小伙伴

潜行 + 右键点击目标即可把 TA 抱起来，再次潜行 + 右键把 TA 丢出去。

可以抱起：猪、鸡、兔子、狼、羊、鹦鹉、村民、牛、熊猫、僵尸、苦力怕、船，以及其他玩家。

十二、假人系统

每个玩家可以召唤最多 2 个假人（全服上限 10 个），让假人帮你挂机、干活。

命令 说明
/fp spawn 在脚下生成一个假人
/fp kill 移除假人
/fp list 查看假人列表
/fp help 查看全部子命令（移动、挖掘、攻击、换肤等）

十三、皮肤更换

命令 说明
/skin 打开皮肤菜单
/skin set <玩家名> 使用某位正版玩家的皮肤
/skin url <图片链接> 通过图片链接加载皮肤
/skin clear 恢复默认皮肤

十四、QQ 群与游戏互通

  • · 在 QQ 群使用绑定命令可以把 QQ 号与游戏 ID 绑定（6 位验证码，10 分钟内有效，退群自动解绑）。
  • · 绑定后可在群内查询在线玩家、查看背包等。
  • · 聊天互通：游戏内发送以 # 开头的消息会转发到 QQ 群；群内以 # 开头的消息也会转发进游戏。
